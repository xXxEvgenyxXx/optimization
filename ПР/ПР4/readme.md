# Практическая работа №4: Мобильная оптимизация и адаптивность

## Цель

Исследование методов оптимизации для мобильных устройств и создание адаптивного дизайна веб-приложений.

## Шаги лабораторной работы

### 1. Задание

#### Шаг 1

- Создайте макет веб-приложения с использованием адаптивных стилей CSS для поддержки различных устройств.

#### Шаг 2: Медиа-запросы для адаптивного дизайна

- Определите и примените медиа-запросы для изменения стилей на различных устройствах (мобильные, планшеты, десктопы).

Для создания адаптивного макета с учетом различных размеров экранов, включая мобильные устройства, планшеты, ноутбуки и большие мониторы, можно использовать следующие кодовые примеры с медиа-запросами для каждого вида экранов:

```css
/* Мобильные устройства (до 600px) */
@media only screen and (max-width: 600px) {
  /* Стили для мобильных устройств */
}

/* Планшеты в портретной ориентации (768px - 959px) */
@media only screen and (min-width: 768px) and (max-width: 959px) {
  /* Стили для планшетов в портретной ориентации */
}

/* Ноутбуки и стандартные мониторы (1280px - 1919px) */
@media only screen and (min-width: 1280px) and (max-width: 1919px) {
  /* Стили для ноутбуков и стандартных мониторов */
}

/* Большие мониторы и телевизоры (от 2400px и выше) */
@media only screen and (min-width: 2400px) {
  /* Стили для больших мониторов и телевизоров */
}
```
