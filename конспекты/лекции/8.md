# Улучшение внутренней структуры ресурса (ЧПУ, robots.txt, карта сайта)

<strong>ЧПУ</strong> - Человекопонятный URL

### Основные преимущества ЧПУ адресов:

- В адресе можно юзать ключевые слова, что положительно влияет на ранжирование страницы

- Естественные ссылки в виде адресов также передают вес по необходимым ключевым словам, содержащимся в ЧПУ

- Улучшается кликабельность сниппетов в выдаче, т.к. ключевые слова подсвечиваются в поиске и привлекают больше внимания

- Облегчает запоминание адресов страниц

- Помогает узнать, о чем страница еще до перехода по ссылке, что уменьшает показатель отказа и помогает привлекать более целевых посетителей

- Упрощает навигацию по сайту

- ЧПУ снижает вероятность появление внутренних дублей

- Упрощает работу с веб-аналитикой

### Ошибки, допускаемые при использовании ЧПУ-адресов:

- Пробелы и служебные символы

- Слишком длинные ЧПУ-адреса

- Цифровые значения в ЧПУ-адресе

- Использование не значимых слов

## Файл robots.txt

<strong>Robots.txt</strong> - текстовый файл, который содержит параметры индексирования сайта для роботов поисковых систем

### Правила в отношении формата и расположения файла:

1. Файл должен носить название robots.txt

2. На сайте должен быть только один такой файл

3. Файл robots.txt нужно размещать в корневом каталоге сайта

4. Файл robots.txt можно добавлять по адресам с субдоменами или нестандартными портами

5. Комментарием считается любой текст после символа #

### Синтаксис файла

1. Файл robots.txt должен представлять собой текстовый файл в кодировке UTF-8

2. Файл robots.txt состоит из групп (директив)

3. Каждая группа может содержать несколько правил, по одному на строку

4. Группа включает следующую информацию:

- К какому агенту пользователя применяются директивы группы

- К каким каталогам или файлам у этого агента есть доступ

- К каким каталогам или файлам у этого агента нет доступа

5. Инструкции групп считываются сверху вниз

6. По умолчанию предполагается, что если доступ к странице или каталогу не заблочен правилом Disallow:, то агент пользователя может их обрабатывать

7. Правила чувствительны к регистру

### Директивы, которые используются в robots.txt

- User-agent;

- Disallow;

- Allow;

- Clean-param;

- Sitemap
