# Способы ускорения загрузки сайта

### В случае снижения загрузки сайта:

1. Уменьшается число просмотров

2. Повышается недовольство клиента

3. Понижается конвенция

2 < t < 3 - идеальное время для загрузки сайта

### Последовательность загрузки страницы:

1. Ввод адреса страницы в браузере и обработка DNS-запроса к серверу, на котором размещается площадка

2. Обработка HTTP-переадресаций при загрузке страницы

3. Подключения браузера к серверу

4. Ответ сервера. Данные передаются от HTTP-сервера к браузеру

5. Обработка загруженной инфы браузером и отрисовка элементов

6. Полная загрузка страницы

### Новые метрики:

1. Первая отрисовка (FP). Это время, спустя которое юзер видит белую пустую страницу в браузере впервые

2. Первая отрисовка контента (FCP). Время, спустя которое на экране появляется первый контент. Это может быть часть панели поиска, фрагмент текста или изображения.

### Скорости:

1. Высокая - менее 1 с

2. Средняя - 1 < t < 2,5 

3. Низкая - более 2,5 с

### Способы ускорения загрузки сайта:

1. Сократить число HTTP запросов. Минимизировать количество изображений, файлов стилей и скриптов

2. Объединить и минифицировать JS и CSS-файлы

3. Реализовать асинхронную загрузку CSS и JS

4. Настроить отложенную загрузку JS-кода

5. Использовать CDN - сеть доставки контента

6. Использовать облачные сервисы

7. Сократить число inline-стилей

8. Реализовать отложенную загрузку имагов, видео, iframe и контента

### Факторы внутренней оптимизации сатйа

1. Составление семантического ядра.

Семантическое ядро - упорядоченный набор слов, их морфологических форм и словосочетаний, которые наиболее точно характеризуют вид деятельности, товары или услуги, предлагаемые сайтом

2. Группировка запросов и определение точек входа

3. Организация структуры

4. Анализ конкурентов

5. Технический аудит

6. Главное зеркало сайта

Главное зеркало - адрес, участвующий в результатах поиска

7. Корректная обработка 404 ошибки

8. Канонические адреса

9. Настройка человекопонятных урлов

10. Хлебные крошки, т.е. внутренняя навигация

11. Навигация через скрипты

12. Удаление битых ссылок

13. Настройка скорости загрузки страницы

14. Кросс-браузерность

15. Клоакинг

16. Регион сайта

17. Редиректы

18. Отсутствие техдублей страниц

19. Верное использование тега noindex, атрибута nofollow
